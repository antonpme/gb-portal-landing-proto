States

Five states, four of them the field's own

Hover, focus and error are the field's, unchanged and measured live; the chevron follows the line into blue because the line and the mark are one control to the person looking at it. Disabled is the only state the field has never had a measurement for, and it is written down as such rather than invented.

Usage
DoDo not
Use a select when the list is closed, short and known in advance, and one value out of it is the answerUse it for a list nobody can hold in their head. Past a few dozen rows the person wants to search, and that is a different control
Give the first row a "pick one" line when nothing is chosen yet, disabled so it cannot be chosen backLeave the first real value pre-selected as if it were a default. A pre-chosen value is an answer given on the person's behalf
Keep the label above the control, in the one caps voice of the systemReplace the label with the pick-one line. It disappears the moment a value is chosen, and the field goes nameless
Let the operating system draw the listBuild a menu to make the list look like the page. The cost is the phone, the keyboard and the focus trap, and the gain is a rounded corner
Sort the options the way the person thinks: most likely first, or plainly alphabeticalSort them the way the database returns them
Accessibility
KeyboardEverything a native select does, because it is one: Tab to it, arrows or first letter to move, Enter or Space to open, Escape to leave it as it was. None of it is written by us and none of it can be broken by us
NameThe caps label carries for and the control carries id. A select with no label has no name, and the pick-one row is not one
The glypharia-hidden="true" and no pointer events: it is a mark, not a control, and the control it marks is already announced as a listbox
DisabledReal disabled. The chevron quiets so the state is visible as well as announced
Target size48 at the smallest rung, the same as every control in the family
Code

Two ways in. The element writes the whole thing; the classes are for a page that already owns its markup, which is how the checkout carries both of its selects.

<!-- the element: label, wrapper, control and glyph -->
<gb-field input-id="country" name="country" label="Country"
          type="select" placeholder="Select a country"
          options="United States|Canada|Italy"></gb-field>

<!-- by hand, where the page owns its own markup -->
<div class="gba-inputwrap gba-select">
  <select class="gba-input" id="country">
    <option>United States</option>
    <option>Canada</option>
  </select>
  <span data-gb-icon="chevron-down" data-gb-icon-size="20" aria-hidden="true"></span>
</div>
